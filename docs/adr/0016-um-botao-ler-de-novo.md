# Um botão só: "Ler de novo"

Com a ADR 0013 (o app nunca abre arquivos), a atualização rápida perdeu o motivo de existir: não há mais detalhes caros para reaproveitar. Os botões "Atualização rápida" e "Releitura completa" viram um só, "Ler de novo", que refaz a lista do disco. Substitui a ADR 0006.
